# Eonx SEO Content Governance

## Rules

1. Never invent statistics.
2. Never invent testimonials.
3. Never publish fake client results.
4. Keep service descriptions accurate.
5. Use one canonical URL per page.
6. Avoid duplicate pages targeting the same intent.
7. Write for people first.
8. Keep claims verifiable.
9. Update outdated information.
10. Keep structured data aligned with visible content.
11. Never create fake client names.
12. Never create fake awards.
13. Never create fake social links.
14. Never create unsupported local claims.
15. Do not keyword stuff.
16. Do not mark up content that is not visible.
17. Do not use SEO to justify low-quality content.
18. Avoid doorway pages (no separate pages for every permutation of "agency", "company", "firm").
19. Human-first content: the same high-quality content serves human visitors, search engines, and AI answer systems.
